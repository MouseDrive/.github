# Getting help

1. **Open the Setup window** in MouseDrive. It checks every requirement (Windows: vJoy DLL, driver, device, axes, buttons; Linux: uinput, permissions, virtual wheel, mouse and keyboard access) and says how to fix each failure. On Linux it also shows the one-time setup commands.
2. **Read the README**: [Quick start](https://github.com/MouseDrive/MouseDrive#quick-start), [Linux](https://github.com/MouseDrive/MouseDrive#linux), [In-game settings](https://github.com/MouseDrive/MouseDrive#in-game-settings) and [Troubleshooting](https://github.com/MouseDrive/MouseDrive#troubleshooting).
3. **Ask in [Discussions → Q&A](https://github.com/MouseDrive/MouseDrive/discussions/categories/q-a).** Mention your MouseDrive version, operating system and game, and paste the output of **Copy diagnostics** (open **Connection details** in the bottom line of the main window).
4. **Found a bug?** Open a [bug report](https://github.com/MouseDrive/MouseDrive/issues/new/choose).

English or Turkish is fine.
